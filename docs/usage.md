# プロフィール 機能・操作・設定

AppDockのユーザー名とアバターを設定するAppletです。AppDock 0.159.0以上が必要です。

発行物の`extensions/at365.profile`をAppDockのextensionsへ配置して有効にします。リボンの「Profile」から設定を開けます。既定では下寄せ・画像のみで、画像がない場合はユーザーアイコンになります。

「ユーザー名」は1〜80文字です。リボンの表示名やツールチップには使用しません。「アバター画像」は共通の画像ライブラリーから選びます。名前と画像は確定時に保存します。全体の設定一覧とApplet管理から同じ設定を編集できます。

設定の見出しと説明は本体の表示言語に合わせて切り替わります。日本語と英語の辞書を同梱し、手動配置でもそのまま使えます。言語の選択肢は本体が対応しているものだけです。入力した名前や選んだ画像は言語を切り替えても変わりません。外部辞書の配置・更新と優先順位は[共通仕様](../../AppDock.at365/docs/applet-localization.md)を参照してください。

名前と画像の選択はAppDockの設定へ保存します。「このPCで設定を保持する」は他のAppletと同じです。登録原画像と画像グループは共有ライブラリーに保存し、画像を外しても原画像は削除しません。
