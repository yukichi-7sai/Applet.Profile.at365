# プロフィール 機能・操作・設定

AppDockのユーザー名とアバターを設定するAppletです。AppDock 0.69.0以上が必要です。

発行物の`extensions/at365.profile`をAppDockのextensionsへ配置して有効にします。リボンの「プロフィール」から設定タブを開けます。既定では下寄せ・画像のみで、画像がない場合はユーザーアイコンになります。

「ユーザー名」は1〜80文字です。リボンの表示名やツールチップには使用しません。「アバター画像」は共通の画像ライブラリーから選びます。名前と画像は確定時に保存します。全体の設定一覧とApplet詳細の設定タブで同じ内容を編集できます。

名前と画像の選択はAppDockの設定へ保存します。「このPCで設定を保持する」は他のAppletと同じです。登録原画像と画像グループは共有ライブラリーに保存し、画像を外しても原画像は削除しません。
